A note about this preview

These installers are unsigned; macOS and Windows may display security warnings. macOS notarization is not included. Windows runtime behavior and live VPN routing still need testing. Use a VPN profile from a provider or IT team you trust.

DropoVPN is a client, not a VPN service. The OpenVPN engine and a working profile are required separately. OpenVPN Connect does not supply the engine DropoVPN needs.

    Choose “Import profile” and select the file from your VPN provider or IT team. Keep any separate certificates alongside the file.

    Connect. Remember. Settle in.

    Enter your VPN credentials and choose “Remember me on this device.” Approve the system administrator prompt to start your tunnel.

GOOD TO KNOW

A little clarity.

What happens when my connection drops?

With automatic reconnection enabled, DropoVPN retries using the same session credentials. Retry delays increase up to 30 seconds. Rejected passwords pause the connection so you can correct them. If the engine exits and must restart, your computer may ask for administrator permission again. Disconnecting manually stops retries.

Where are my saved passwords stored?

On your computer, encrypted with Electron safeStorage using macOS Keychain or Windows DPAPI. DropoVPN supplies credentials to the local OpenVPN engine when needed. You can forget a saved password from the profile menu. Windows DPAPI does not protect against every program running as your Windows user.

Does it work with my existing VPN?

DropoVPN supports imported OpenVPN TUN profiles with username/password or certificate authentication. One-time codes, browser sign-in, proxy authentication, hardware tokens, TAP profiles, and connection blocks are not supported in this preview. Some provider-specific configurations may need a compatible export.

Does DropoVPN include a kill switch?

No. Your profile controls routing, and traffic is not automatically blocked while reconnecting. A split-tunnel profile only routes the destinations it specifies through the VPN.

Is it free and open source?

Yes. DropoVPN’s application source is available under the MIT license. OpenVPN is installed separately and has its own license. Read the source or report an issue on GitHub.
